# Hosted site (GitHub Pages)

`index.html` is the complete Dee-Mard app as one self-contained file, served by
GitHub Pages from this `docs/` folder. It is a copy of the live claude.ai
artifact (https://claude.ai/artifact/FChRzUge9wzUDsCx8BLtVg) as of 3 Nov 2026.

To update the site, replace `index.html` with a newer build and push.
